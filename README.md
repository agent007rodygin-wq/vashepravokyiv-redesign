# Ваше Право — Сучасний редизайн веб-сайту

> Преміальний редизайн сайту юридичної компанії «Ваше Право» (медичне право та ліцензування в Україні, керівник: Родигіна Олександра Олександрівна).
> Побудовано на базі принципів **Apple Human Interface Guidelines (HIG)** зі збереженням 100% авторського контенту, виправленням критичних багів старих шаблонів та інтерактивними анімаціями.

## 🍏 Ключові особливості нової дизайн-системи:
- **Типографіка:** Гарнітура **PT Serif** для витриманого преміального юридичного стилю.
- **Колірна палітра:** Глибока база `Primary Navy` (`#0D2B45`), фірмовий інтерактивний акцент `Action Blue` (`#0066CC`), легке тло `Parchment` (`#F5F5F7`), білі картки з тонкими hairline-бордерами.
- **Елементи інтерфейсу:** `Pill`-кнопки (`border-radius: 9999px`), скляний хедер із розмиттям `backdrop-filter: blur(20px)`.
- **Плавні переходи (Apple Glass Paper-Flip):** напівпрозора матова вуаль, що м'яко ковзає в напрямку руху між розділами сайту.
- **Анімовані лічильники:** Плавне кінематографічне накручування цифр (від 0 до 100% та 2000 р.).
- **Офіційна презентація:** Вбудована інтерактивна галерея усіх 12 слайдів високої роздільної здатності (2560x1440).
- **Каталог 12 напрямків послуг:** Модальні вікна з повним юридичним переліком документів.
- **Виправлення багів:** Усунуто некоректні телефонні префікси, злипання адрес і залишкове сміття чужого шаблону.

## 📁 Структура репозиторію:
- `index.html` — Головна сторінка сайту
- `assets/css/style.css` — Стилі нової дизайн-системи
- `assets/js/main.js` — Логіка галереї, модальних вікон, переходів та лічильників
- `assets/slides/` — 12 слайдів офіційної презентації компанії
- `assets/img/` — Логотип високої роздільної здатності та фото-аватарка
- `site-analysis.json` — Повний технічний та UX аудит сайту
- `design-system.json` — Специфікація токенів нової дизайн-системи
- `redesign-spec.json` — Детальний посторінковий план редизайну
- `changelog.md` — Журнал усіх внесених покращень
- `backup/` — Повний оригінальний бекап 6 сторінок сайту з Weblium
